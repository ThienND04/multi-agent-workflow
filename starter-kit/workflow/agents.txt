# Danh sách agent và cách đánh thức. Chủ dự án điền; agent không sửa file này.
#
# Mỗi dòng:  <ID>  <vai>  <chế độ>  <lệnh, tên subagent, hoặc ghi chú>
#
# Ba chế độ:
#   subagent : Master tự gọi subagent này ngay trong phiên chat của Master (Claude Code, ứng dụng desktop
#              hoặc dòng lệnh). Cột cuối là tên subagent trong .claude/agents/ (coder, coder-pro, tester).
#              Không cần cài thêm gì. watch.sh không đánh thức, không báo.
#   auto     : watch.sh tự chạy lệnh và thêm lời nhắn đánh thức vào cuối lệnh. Cần công cụ AI chạy được
#              bằng lệnh (xem SETUP.md, bước 3). Agent chạy KHÔNG có người canh: chỉ cấp quyền cần thiết,
#              không bao giờ cấp quyền push.
#   manual   : watch.sh chỉ báo (màn hình và Telegram) rằng agent này có việc; bạn tự mở phiên cho nó.
#              Hợp với công cụ không chạy được bằng lệnh, ví dụ Antigravity.
#
# Lệnh mẫu cho chế độ auto (kiểm tra lại theo phiên bản công cụ bạn cài):
#   Claude Code : claude -p --permission-mode acceptEdits --model sonnet
#   Codex CLI   : codex exec --full-auto
#   Gemini CLI  : gemini --yolo -p
#   Tài khoản Claude thứ hai:
#     env CLAUDE_CONFIG_DIR=/c/Users/<tên-bạn>/.claude-acc2 claude -p --permission-mode acceptEdits --model sonnet
#
# Master: để manual, vì bạn đang chat với Master trong phiên chính. Khi có việc chờ Master, watch.sh báo bạn;
# bạn nói với Master "Xử lý việc đang chờ".
# Mỗi phiên chat là một Master. Một phiên làm lần lượt nhiều tính năng vẫn là master-01.
# Mở thêm phiên để làm song song thì thêm master-02 và nói với phiên mới "Bạn là master-02".

master-01     master  manual    phiên chat chính

coder-01      coder   subagent  coder
tester-01     tester  subagent  tester
