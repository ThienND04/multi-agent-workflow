# Danh sách agent và cách đánh thức. Chủ dự án điền; agent không sửa file này.
#
# Mỗi dòng:  <ID>  <vai>  <chế độ>  <lệnh, tên subagent, hoặc ghi chú>
#
# Bốn chế độ:
#   subagent : Master tự gọi subagent này ngay trong phiên chat của Master (Claude Code, ứng dụng desktop
#              hoặc dòng lệnh). Cột cuối là tên subagent trong .claude/agents/ (coder, coder-pro, tester).
#              Không cần cài thêm gì. watch.sh không đánh thức, không báo.
#   auto     : chạy ngầm qua workflow/agent.sh (với claude/agy) hoặc watch.sh.
#              agent.js tự lưu session ID vào workflow/.run/sessions/<ID>.json để dùng lại phiên cũ
#              khi đánh thức lại; chưa có hoặc truyền --new (`agent.sh new <ID>`) thì tạo phiên mới.
#              Agent chạy KHÔNG có người canh: chỉ cấp quyền cần thiết, không cấp quyền push.
#   window   : watch.sh mở một CỬA SỔ terminal mới, chạy công cụ ở dạng tương tác với lời nhắn gửi sẵn.
#              Bạn thấy agent làm gì, trả lời được khi nó xin quyền. Cửa sổ còn mở mà có việc mới thì
#              watch.sh không mở thêm, chỉ báo bạn gõ "Xử lý việc đang chờ" vào cửa sổ đó.
#   manual   : watch.sh báo (màn hình và Telegram) và chép sẵn lời nhắn vào clipboard; bạn mở công cụ
#              rồi dán. Hợp với công cụ chỉ có giao diện, ví dụ ứng dụng Antigravity.
# Chế độ auto và window cần công cụ AI dòng lệnh (cài theo hướng dẫn của từng công cụ). Lệnh phải kết thúc bằng tham số
# nhận lời nhắn, vì watch.sh thêm lời nhắn vào cuối lệnh.
#
# Lệnh mẫu (chạy trên Linux qua workflow/agent.sh và watch.sh):
#   Claude Code   : claude --permission-mode acceptEdits --model sonnet
#   Antigravity   : agy --mode accept-edits --effort high
#   Xem model của Antigravity: agy models. Có thể thêm --effort low|medium|high|max.
#   Tài khoản Claude thứ hai:
#     env CLAUDE_CONFIG_DIR=/home/<tên-bạn>/.claude-acc2 claude --permission-mode acceptEdits --model sonnet
#
# Lưu ý: giữ nguyên lệnh gốc (không cần tự thêm -p, --output-format hay --resume); workflow/agent.js
# tự gắn các cờ stream-json, --session-id / --resume và -p=<prompt> đúng chuẩn từng CLI.
#
# Master: để manual, vì bạn đang chat với Master trong phiên chính. Khi có việc chờ Master, watch.sh báo bạn;
# bạn nói với Master "Xử lý việc đang chờ".
# Mỗi phiên chat là một Master. Một phiên làm lần lượt nhiều tính năng vẫn là master-01.
# Mở thêm phiên để làm song song thì câu đầu tiên nói với phiên mới: "Bạn là master-02." (master-02, master-03
# đã khai sẵn bên dưới; cần nhiều hơn thì thêm dòng). Không nêu ID mà đang có tính năng dở, Master sẽ hỏi lại.

master-01     master  manual    phiên chat chính
master-02     master  manual    phiên chat song song thứ hai
master-03     master  manual    phiên chat song song thứ ba

# Mặc định dùng chế độ auto với claude và agy để Master (dù là Claude hay Antigravity)
# và watch.sh tự tạo/đánh thức chạy ngầm, tự lưu & dùng lại session ID cố định theo từng ID.
coder-01      coder   auto      claude --permission-mode acceptEdits --model sonnet
coder-02      coder   auto      agy --mode accept-edits
tester-01     tester  auto      agy --mode accept-edits --effort high
tester-02     tester  auto      claude --permission-mode acceptEdits --model opus

# coder-01    coder   subagent  coder
# coder-03    coder   subagent  coder-pro
# tester-01   tester  subagent  tester
# tester-03   tester  manual    Antigravity (ứng dụng giao diện, dán lời nhắn từ clipboard)
