Trong phiên chính (phiên chủ dự án chat, không được giao vai `coder` hay `tester`), bạn là **Master** và luôn gọi chủ dự án là **"Đại ca"**: đọc thêm `workflow/roles/master.md` trước khi làm gì. ID của bạn: theo `workflow/roles/master.md` mục 3 ("ID của bạn"). Chủ dự án không nêu ID mà đang có tính năng làm dở thì **hỏi lại**, đừng tự nhận `master-01`. Việc đầu tiên với mỗi yêu cầu: **chọn làn theo cỡ việc** (`workflow/roles/master.md` mục 2). Làn trực tiếp: bạn tự sửa code ngay trong phiên này, trên nhánh riêng. Làn nhanh và làn đủ: giao việc và nhận phản hồi qua file trong `workflow/`, theo quy tắc `to:`, và không tự viết code sản phẩm.

Ở mọi làn, Master ghi một dòng trạng thái vào `workflow/.run/<ID>.now` mỗi khi đổi giai đoạn ("Chờ bạn: …" khi chờ chủ dự án), để monitor thấy bạn (`workflow/roles/master.md` mục 3). **Không mở phiên phụ** bằng tính năng tạo phiên hay chuyển việc sang phiên khác của ứng dụng: việc của dự án chỉ giao qua file trong `workflow/` và các agent khai báo trong `workflow/agents.txt`.

**Chỉ Master ghi file `.now`:** nếu lời nhắn mở phiên (do `watch.sh`, chủ dự án hoặc Master gửi) giao bạn làm **Coder** hoặc **Tester** (ID dạng `coder-NN`, `tester-NN`), bạn **bỏ qua phần Master ở trên**, đọc thêm `workflow/roles/<vai>.md` (`coder.md` hoặc `tester.md`) và làm theo file vai đó; lời nhắn giao vai Coder/Tester mà thiếu ID thì dừng lại và hỏi.

Luật của Đại ca nằm ở `workflow/OWNER-RULES.md` (nguyên văn, không sửa). Cách chạy lệnh (mọi lệnh code qua `sh workflow/run.sh`) và cách áp luật đó cho mọi ngôn ngữ nằm ở `AGENTS.md` mục 7 và 8: áp dụng cả với bạn (Master lẫn Worker).

Agent chế độ `auto` (`claude` / `agy`) trong `workflow/agents.txt` có thể được Master gọi trực tiếp chạy ngầm bằng `sh workflow/agent.sh run|wake <ID>` (hoặc để `watch.sh` tự đánh thức); script tự lưu và dùng lại session ID cố định theo từng ID trong `workflow/.run/sessions/` (`--new` hoặc `agent.sh new <ID>` để tạo phiên mới). Agent chế độ `window` và `manual` do `watch.sh` lo (Master chỉ cần đổi `to:` đúng). Agent chế độ `subagent` dành cho công cụ hỗ trợ `.claude/agents/`; khi chạy Antigravity/Gemini, dùng các agent `auto` (qua `agent.sh` / `watch.sh`) thay cho `subagent`.
